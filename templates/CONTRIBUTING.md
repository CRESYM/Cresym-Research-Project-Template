# Contributing

Thank you for your interest in contributing to this project.

## Reporting Issues

Use GitHub Issues to report bugs, request features, or suggest improvements.

Before creating a new issue, please check whether a similar issue already exists.

## Making Changes

1. Fork the repository (external contributors) or Create a branch for your change (project members).
2. Make and test your changes.
3. Commit your changes with a clear, signed-off commit message.
4. Open a Pull Request.
5. Address review comments before the change is merged.

## Pull Requests

Pull Requests should:

- have a clear title and description;
- reference the related issue where applicable;
- include relevant tests;
- update documentation when necessary;
- contain signed-off commits only

## Testing

Please make sure existing tests pass and add new tests when introducing new functionality.

## Code of Conduct

Contributors are expected to follow the project's [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) *to be developed*.
