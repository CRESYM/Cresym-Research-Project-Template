# Code of conduct 

This project applies the [Mozilla Community Participation Guidelines.](https://www.mozilla.org/en-US/about/governance/policies/participation/) 

All participants, including users, contributors and maintainers are expected to follow these guidelines in all project spaces, such as issues, pull requests, discussions and project meetings. 

## Reporting
Please report unacceptable behavior to the project's teams at helpdesk@cresym.eu.
