# CRESYM-Research-Project-Template
Template and standards for Cresym research project repositories

## Purpose
This repository provides a common starting point for research software projects developed within or supported by CRESYM.

The objective is to help research projects follow consistent practices for:
- repository structure
- documentation
- licensing
- contribution
- governance 
- testing
- open-source readiness

The template is intended to support the transition of research results into reusable and maintainable open-source assets.

## Repository Structure
The recommended structure and required files will be developed and validated in this repository before being adopted for CRESYM project repositories.

```
templates/
|-- README.md               # Project README
|-- CONTRIBUTING.md
|-- GOVERNANCE.md
|-- MAINTAINERS.md (*to be developed*)
|-- CODE_OF_CONDUCT.md
|-- LICENSING.md
|
|-- docs/                   # Project documentation
|   |-- architecture.md
    |-- development.md
    |-- example.md

```
